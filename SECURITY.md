# Security Policy

## Supported Versions

We are currently in active development. Security updates are applied to the `main` branch and pre-release builds.

| Version | Supported |
| ------- | ------------------ |
| main (0.x) | :white_check_mark: |
| < 0.1.0 | :x: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in **Rusk**, please **do not create a public issue**. Instead, report it privately so we can fix it before it is disclosed.

### How to report
- **Email:** Send the details to `contact@vagno.dev`

- **GitHub:** Use the **Report a vulnerability** button under the **Security** tab of this repository.


### What to include in your report
- A description of the vulnerability and its potential impact.

- Detailed steps to reproduce the issue (or a proof-of-concept snippet).

- Any relevant environment details (OS, version, configuration).


### What to expect
- **Acknowledgment:** We will acknowledge receipt of your report within **48 hours**.

- **Updates:** We will keep you updated on the progress towards a fix.

- **Disclosure:** Once a patch is ready and released, we will publish a security advisory and credit your contribution (unless you prefer to remain anonymous).
